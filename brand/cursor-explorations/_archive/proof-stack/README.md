# Proof Stack

Provisional Cursor exploration. Not an approved identity.

## Palette
Workshop paper `#f1eadb`, Soft black `#171613`, Persimmon `#ff5b3d`, Ultramarine `#3157ff`, Acid leaf `#c8ef52`.

## Clear space
Keep clear space ≥ 1/4 mark width on all sides.

## Minimum size
24 px for color mark; 32 px preferred for mono/print.

## Misuse
No glow, no mascot eyes, no Wi-Fi arcs, no houses in the umbrella mark.

## Licensing
Prototype uses system fonts. Final packaging must ship OFL fonts locally before production.
