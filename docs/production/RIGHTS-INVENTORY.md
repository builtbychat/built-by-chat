# Rights and provenance inventory

No asset enters a stream, thumbnail, recap, sponsor deck, or repository without a source, license/permission basis, scope, and reviewer. “Found online” is not a permission basis.

| Asset class | Launch source/status | Required evidence |
|---|---|---|
| Tiny Signal Club logos/wordmarks/templates | Original code-native SVG in this repository; brand rights reserved | Git history and `TRADEMARKS.md` |
| Tiny Internet Town hero | Generated through the image workflow and visually reviewed; no embedded mark/text | Brand guide provenance plus approved prompt/run summary for future revisions |
| Source code | Project-authored or dependency-managed; project source under MIT | License, lockfile, dependency notices/audit |
| Fraunces, Manrope, DM Mono | Named as preferred typography but font files are not distributed by this repository | Before bundling, store the exact font version, source, license file, and redistribution terms; otherwise use fallbacks |
| Phaenex portrait/camera | Owner-controlled likeness and recording | Explicit owner approval for each reusable portrait pack |
| Audience ideas | Moderated contribution with accepted submission terms and credit relationship | Consent version, idea ID, moderation status |
| Music and sound effects | None approved yet | Track title, creator, source, license, commercial/simulcast/VOD/clip scope, attribution, receipt if paid, expiry |
| Third-party screenshots/code/logos | Not approved by default | Permission or documented commentary/fair-use review; remove confidential data and follow trademark rules |
| Guest voice/likeness | No guests approved yet | Release covering livestream, VOD, clips, promotion, and commercial use; guardian review for minors |
| Game/platform footage | None planned at launch | Current platform/publisher permission and music considerations |

## Pre-show clearance

- Use only entries marked approved for all intended destinations: YouTube, Twitch, VOD, clips, social, sponsor materials, and repository.
- Inspect the OBS media-source list and recording folder; a licensed livestream track may still be prohibited in VODs or clips.
- Keep license files, receipts, releases, and source links in a private rights folder outside the public repository when they contain personal or billing data.
- Generated output receives the same review as any other asset: originality concerns, trademarks, recognizable people, embedded text, and provenance.
- If rights are uncertain, replace the asset with original code-native art, silence, or a cleared fallback before rehearsal.
