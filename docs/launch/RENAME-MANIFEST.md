4. Claim free identities through user-operated CAPTCHA/OTP/terms/2FA checkpoints.
5. Configure domain, email, Access, Turnstile, aliases, OBS browser sources, and redirects.
6. Run an unlisted renamed rehearsal.
7. Approve the public transition message.

Rollback remains available until the external migration gate passes.
