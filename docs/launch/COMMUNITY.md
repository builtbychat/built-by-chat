# Discord setup

Create the **Tiny Signal Club** server only after explicit approval. Suggested order:

1. Read-only `welcome` and `announcements`.
2. `live-chat`, `town-square`, `idea-workshop`, `bug-reports`, `clips-and-memes`, and `contributors`.
3. Private `moderators` visible only to Moderator and Founder.

Roles: Founder (owner only), Moderator (safety tools), Builder (merged contributors), Tester (repeat playtesters), Resident (community member). Do not use paid roles to grant moderation or voting influence. Announcements can link to site voting; Discord polls are nominations only.
