# Built by Chat brand guide

**Tagline:** “The internet decides. We build it live.”

## Idea

Built by Chat feels like a porch light in a digital town: welcoming, curious, quietly technical, and visibly made by people. The house inside a chat bubble represents community; the terminal chevron represents building in public.

## Palette

| Token | Hex | Use |
|---|---:|---|
| Midnight | `#0b1026` | Primary background |
| Night | `#111936` | Secondary background |
| Cyan | `#5de4e7` | Interaction, links, live energy |
| Coral | `#ff7b72` | Votes, dates, emphasis |
| Cream | `#f8dfb6` | Warm editorial panels |
| Ink | `#eef6ff` | Primary text |
| Muted | `#a8b7d6` | Secondary text |

Maintain WCAG AA contrast for functional text. Cyan on midnight and midnight on coral/cream are preferred pairs.

## Type and spacing

- Headlines: Fraunces Semibold/Bold. Fallback Georgia.
- UI and body: Manrope. Fallback system sans-serif.
- Labels and technical details: DM Mono. Fallback monospace.
- Base spacing unit: 8 px. Common gaps: 8, 16, 24, 32, 48, 64 px.

## Voice

Warm, specific, playful, and honest about uncertainty. Say “we’ll try it live,” not “revolutionary interactive content.” Invite people into decisions without pretending every suggestion can ship. Never frame payment as influence.

## Logo rules

Keep clear space equal to one-quarter of the icon width. Do not recolor individual parts outside approved monochrome use, stretch, rotate, add shadows, or place over a busy image without a midnight field. “Built by Chat,” the icon, characters, and original media are reserved marks even though the source code is MIT licensed.

## Thumbnail rules

Use one short 2–5 word title, an episode capsule, one clear vote-result line, and a consistent Phaenex portrait circle on the lower right. Do not put critical text outside a 60 px safe margin. Coral identifies the episode; cyan identifies the community result.
