# Tiny Signal Club brand guide

**Primary tagline:** “Small signals become big, strange things.”
**Participation line:** “Tune in. Choose something weird.”

## Brand architecture

- **Tiny Signal Club** is the project-agnostic studio and community.
- **Tiny Internet Town** is Project One, not the umbrella identity.
- **The Modem Picnic** is the relaxed Sunday playtest and community gathering.
- Future projects receive independent titles under “Tiny Signal Club presents.”

“Tiny” describes the starting signal—an idea, prompt, vote, test, or contribution—not the scale of the result. The club may make games, worlds, stories, utilities, animations, physical experiments, or formats not yet imagined.

## Idea

Tiny Signal Club feels like one porch light blinking on across a strange digital landscape, followed by many others. It is welcoming, curious, quietly technical, and visibly made by people. The signal bubble icon combines a conversation shape with broadcast arcs and one coral source dot: a small input traveling outward and becoming shared work.

## Community language

| Purpose | Preferred language |
| --- | --- |
| Opening ritual | Signal Check |
| Viewer idea | Incoming Signal |
| Vote accepted | Signal Received |
| Weekly update | Signal Bulletin |
| Project announcement | New Transmission |
| Discord/community space | The Clubhouse |
| Sunday gathering | The Modem Picnic |
| Project archive | Signal History |
| Shipped audience result | Signal Made Real |

Use these as light recurring rituals, not jargon viewers must memorize.

## Palette

| Token | Hex | Use |
|---|---:|---|
| Midnight | `#0b1026` | Primary background and night-sky field |
| Night | `#111936` | Secondary background |
| Signal cyan | `#5de4e7` | Interaction, links, live energy, signal bubble |
| Source coral | `#ff7b72` | Votes, dates, signal origin, emphasis |
| Cream | `#f8dfb6` | Warm editorial panels |
| Ink | `#eef6ff` | Primary text |
| Muted | `#a8b7d6` | Secondary text |

Maintain WCAG AA contrast for functional text. Cyan on midnight and midnight on coral/cream are preferred pairs. Never rely on coral/cyan alone to communicate state.

## Type and spacing

- Headlines: Fraunces Semibold/Bold. Fallback Georgia.
- UI and body: Manrope. Fallback system sans-serif.
- Labels, signals, and technical details: DM Mono. Fallback monospace.
- Base spacing unit: 8 px. Common gaps: 8, 16, 24, 32, 48, 64 px.

## Voice

Warm, specific, playful, and honest about uncertainty. Invite people into a club doing a real experiment together. Prefer “send a signal,” “let’s test it,” and “here’s what shipped” over hype such as “revolutionary interactive content.” Never imply every suggestion can ship or that payment buys influence.

The voice can be peculiar without becoming childish. Explain participation plainly before using club rituals.

## Logo rules

The icon is a signal bubble with two broadcast arcs and one coral source dot. Keep clear space equal to one-quarter of the icon width. Do not add a house or town element to the umbrella mark; project-specific art can carry those motifs. Do not recolor individual parts outside approved monochrome use, stretch, rotate, add shadows, or place over a busy image without a midnight field.

“Tiny Signal Club,” the signal bubble, project titles, characters, and original media are reserved marks even though source code is MIT licensed.

## Motion and sound

Motion begins with one small coral signal and expands into cyan rings, map lights, project icons, or a connected audience. Keep the reduced-motion version semantically complete. Audio cues should be gentle and paired with visible text: signal received, vote warning, result, and shipped patch.

## Thumbnail rules

Use one short 2–5 word title, an episode capsule, one clear vote-result line, and a consistent Phaenex portrait circle on the lower right. Add “Tiny Signal Club presents” only when it remains readable; Project One thumbnails should prioritize **Tiny Internet Town**. Do not put critical text outside a 60 px safe margin. Coral identifies the episode/source signal; cyan identifies the community result.

## Project-title lockup

Use this hierarchy:

```text
TINY SIGNAL CLUB PRESENTS
Tiny Internet Town
```

The umbrella name should be smaller than the project title on episode-specific art. On channel banners, sponsor decks, and the site masthead, the umbrella name leads.
