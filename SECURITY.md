# Security policy

Privately report suspected vulnerabilities to `security@builtbychat.com`. Include impact, reproduction steps, affected route/version, and a safe contact method. Do not test against production voters, access data that is not yours, degrade the live show, or publish details before a fix is available.

We aim to acknowledge reports within three business days. No credentials, raw viewer IPs, stream keys, recovery codes, or account secrets belong in this repository. Supported security fixes target the latest release.
